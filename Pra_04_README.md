Pra_04 - WebApplication1

Overview

This repository contains the Pra_04 practice web application (WebApplication1) — a simple ASP.NET Web Forms project that demonstrates an "Online Event Registration Portal" form (WebForm1.aspx).

Requirements

- .NET Framework 4.8
- Microsoft Visual Studio (2019/2022/2026) with ASP.NET Web Development workload

Quick start

1. Open the solution: WebApplication1.sln (located in the project folder).
2. Build the solution (Build -> Build Solution).
3. Run the project (F5) to launch in the local development web server.

Project structure

- WebApplication1/ (solution root)
  - WebForm1.aspx          -- Registration form (HTML + inline CSS added)
  - WebForm1.aspx.cs       -- Code-behind for the form (event handlers)
  - Web.config
  - WebApplication1.sln

Notes

- The form markup and a responsive CSS style block were added directly to WebForm1.aspx to present the form as a centered card and make inputs/buttons styled and mobile-friendly.
- The project targets .NET Framework 4.8. Do not retarget unless you intend to migrate to a newer .NET version.

How to modify

- To change the UI, edit WebForm1.aspx.
- To add server-side logic, edit WebForm1.aspx.cs and implement event handlers.
